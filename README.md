# FUTURE — personal wishlist

A responsive, Apple-inspired white-aesthetic wishlist website built with plain HTML, CSS and JavaScript for GitHub Pages.

## What's included
- Home page with five category cards
- Separate pages for Apple, IKEA, Nothing, Rolex and Royal Enfield
- Product cards with features, price labels, source links and price notes
- Responsive layout and subtle reveal/hover animations
- Reduced-motion support
- Locally stored SVG placeholder artwork in each images/ folder

## Important image note
The SVG files are original illustrative placeholders, not official product photographs. Replace them with product images you have permission to host. Keep the same file names to avoid changing the code, or update the `image` paths in `js/products.js`.

## Price note
Prices are reference values collected from official or retailer sources where indicated, observed around 20 October 2026. They are not live-updating prices. Recheck every price, variant and availability on the linked source before purchase. Some Nothing prices are deliberately marked "Verify current price" because a reliable India price was not confirmed in this starter.

## Run locally
Open `index.html` in a browser. If your browser restricts local scripts, use a simple local web server.

## Publish with GitHub Pages
1. Create a repository named `future-collection`.
2. Upload the contents of this folder to the repository root (not the containing folder).
3. Open repository Settings → Pages.
4. Choose deploy from the `main` branch and `/ (root)`, then save.
5. Wait for the published URL to appear.

All prices, product choices and text can be edited in `js/products.js`.
